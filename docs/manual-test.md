# gsv 手動テスト手順（実 API）

前提: `docs/setup.md` 完了、テスト用スプレッドシート（2 タブ以上、日本語・長文・改行入りセルを含む）がマイドライブにある。

1. `rm ~/.config/gsv/token.json && ./gsv` → ブラウザ認可 → TUI 起動、My Drive が展開済み
2. `j`/`k` で移動、フォルダで `l` → `⟳ loading…` の後に子が出る。`h` で閉じる / 親へ
3. スプレッドシートで `l` → 右ペインに罫線付きグリッド、ステータスに `<名前> / <タブ>  A1  <値>`
4. `5j` `3l` `gg` `G` `0` `$` `Ctrl-d` `Ctrl-u` でカーソル移動、画面外でスクロール
5. 長文セルで `…` 表示 → ステータスに全文、`K` / `Enter` でポップアップ、`q` で閉じる
6. `gt` `gT` `2gt` でタブ切替
7. `/キーワード` → `n` / `N`、存在しない語で `E486`
8. `r` でタブ再読込、ツリーで `r` でフォルダ再読込
9. `Ctrl-w h` / `Ctrl-w l` / `Ctrl-w w` でフォーカス移動、`Ctrl-n` でツリー表示切替
10. `:e <ブラウザからコピーした URL>` で直接オープン
11. `:find <名前の一部>` で「Search: …」ルートに結果
12. Shared with me / config.yaml の共有ドライブを展開できる
13. `:foo` で `E492`、`:q` で終了
14. `LANG=ja_JP.UTF-8 RUNEWIDTH_EASTASIAN=1 ./gsv` でも罫線がずれない
15. Wi-Fi を切って `r` → ステータスに赤字エラー、ノードに `!`、復帰後 `r` で回復
