# gsv

Google スプレッドシートをターミナルで閲覧する、読み取り専用の vim ライク TUI。

- 左ペイン: Drive ツリー（My Drive / Shared with me / 設定した共有ドライブ）
- 右ペイン: 罫線付きグリッド（列幅 12 固定、全文はステータスライン / `K`）

セットアップ: [docs/setup.md](docs/setup.md)

## 主なキー

| キー | 動作 |
|---|---|
| `h` `j` `k` `l` / `gg` `G` `0` `$` / `Ctrl-d` `Ctrl-u` | 移動（カウント可） |
| `l` / `Enter`（ツリー） | フォルダ展開 / シートを開く |
| `gt` `gT` `{n}gt` | タブ切替 |
| `/` `?` `n` `N` | 検索 |
| `K` / `Enter`（表） | セル全文 |
| `r` | 再読込 |
| `Ctrl-w h/l/w` / `Ctrl-n` | ペイン移動 / ツリー表示切替 |
| `:e <URL\|ID>` / `:find <名前>` / `:q` | 直接オープン / Drive 検索 / 終了 |
